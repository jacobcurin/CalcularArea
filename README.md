\# Calculadora de áreas de figuras geométricas



Actividad práctica desarrollada en C# que permite calcular el área de distintas figuras geométricas a partir de las medidas ingresadas por el usuario.



\## Figuras disponibles



\- Círculo

\- Cuadrado

\- Rectángulo

\- Rombo



\## Tecnología utilizada



\- C#

\- .NET

\- Aplicación de consola



\## Conceptos y métodos utilizados



\- `double.TryParse()`

\- `while`

\- `if`

\- Métodos

\- Parámetros y valores de retorno

\- Validación de datos ingresados por el usuario



\## Funcionamiento



El usuario ingresa la figura geométrica que desea calcular y posteriormente las medidas necesarias para realizar el cálculo.



El programa valida que los datos ingresados sean numéricos y que las medidas sean mayores a cero. Finalmente, llama al método correspondiente y muestra el área calculada.



\## Objetivo



Practicar la creación y utilización de métodos en C#, junto con validaciones, estructuras condicionales y manejo de datos ingresados por consola.
